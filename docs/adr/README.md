# Architecture Decision Records — Index

Queryable index of every ADR. **Read this first**, then open only the records
relevant to what you're working on — ADRs are not auto-loaded into context, so
this list is how you discover which ones exist. Grep it by keyword (e.g. `combat`,
`mana`, `bot`, `layer`) to find the decision that touches your area.

**Maintenance:** add one line here whenever you create a new ADR, and take the
NEXT free number — the filename number is canonical and must be unique. The
drift guard is `scripts/__tests__/adr-index.test.ts`; it runs in the node
project, so a missing row or a reused number reds the gate, not a review.

> **Numbers are unique, and guarded.** The two collisions this file used to
> warn about are gone (issue #3527): `0020-destroy-replacement-via-framework`
> became `0125` and `0021-general-phasing-via-holding-bundle` became `0126`,
> with every citation rewritten. `0020` and `0021` now mean the bot-timing and
> opponent-model records only. `scripts/__tests__/adr-index.test.ts` reds on a
> duplicate number, on a record with no row here, and on a row pointing at no
> file — so cite by NUMBER with confidence.
